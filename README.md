# Lista de Tarefas

Um projeto simples onde você pode adicionar, deletar e concluir tarefas.

## Como acessar:

- Copie o link (URL) do arquivo HTML.
- Acesse o HTML Preview.
- Cole o link no campo indicado e clique em Preview.

## Como usar:
- Utilize os botões Adicionar, Excluir e Feito para gerenciar suas tarefas.
- O projeto utiliza localStorage para salvar as tarefas no navegador. Assim, elas continuam salvas mesmo depois que você fecha a página. As tarefas ficam salvas no navegador e dispositivo utilizados.

## Tecnologias utilizadas:
- HTML/CSS
- JavaScript
